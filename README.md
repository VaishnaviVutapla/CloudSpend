# CloudSpend

Full React + Firebase cloud expense tracker. Features: authentication, password reset, dashboard, income/expense transactions with edit/delete/search/filter/sort, analytics, budgets with alerts, profile, dark/light theme, Firestore security rules, and Firebase Hosting config.

Setup: copy `.env.example` to `.env`, add your Firebase Web App config, run `npm install`, then `npm run dev`. For hosting: `npm run build` then `firebase deploy`.
